# RCR Lighting — control page

Web Bluetooth control page for the RCR e-bike lighting controller, published at
**https://jklaus1.github.io/rcr-lighting-app/**. Open it in Chrome on Android (or any Chromium browser with
Web Bluetooth), tap *Connect* and pick the board; *Try the demo* runs a simulated controller with no hardware.
Add it to the home screen for a full-screen app that also opens offline.

The source of truth is `web/` in the firmware repository (JKlaus1/RCR-80v-Lighting, branch `firmware/v0.2`);
this repo is a publish copy for GitHub Pages. To update: copy `web/*` here and push.
