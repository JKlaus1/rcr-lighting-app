Connect to the controller

  1. Switch the key on. The first phone can pair in the 2 minutes after power-up. To add another phone later, hold the handlebar button for 5 seconds (the hazards flash while it opens), or use Add a phone on Setup from a phone that's already paired.
  2. Tap Connect and pick “RCR Lighting”. Android asks to pair the first time.
  3. On a Windows PC, Chrome cannot do the pairing itself: pair in Windows Settings → Bluetooth → Add device → RCR Lighting while the pairing window is open, then press Connect here.

To have this page find the controller by itself every time it opens: in Chrome, open chrome://flags/#enable-web-bluetooth-new-permissions-backend, set it to Enabled, relaunch Chrome, then Connect here once. After that there is no chooser on a reload, and the page connects when the key comes on.

The demo runs a simulated controller in this page. Tap the bike inputs on the Live tab to work the switches.

Outputs

    Bike inputs

    Changes = how often an input switched since key-on or the last reset. Cut-outs = a lamp's current dropping out while its output was on (low/high beam checked every millisecond). A lamp that cuts out with no input changes is the lamp or its supply; an input that changes with nobody at the switch is a signal line dropping out.

    Quick

    Underglow

    Turn signals

    Rear light

    Each output drives one chain of LEDs. Pick the LED chip, split the chain into segments and give each a job. Bike → Add a light is the easy way to set a strip up; drawing strips on photos (Photo layout) is the way to set segments and positions for the position-based underglow effects. The segment editor under each strip is for fine tuning. Changes apply when you tap Apply.

    Layout

    Tail / brake Turn Underglow Unused

    Hollow dot: first pixel. Filled dot: last pixel. Arrows show the data direction. Dashed bars are runs drawn on the other view, at their depth: drag one sideways to set it.

    Runs

    Chains and outputs

    A run is one strip drawn on a photo; each straight stretch between two taps becomes one segment. Chain runs that share a wire and give each chain an output. Positions are saved on this phone, not on the board, until you send them.

    Pixel finder

    Move the slider to light one pixel white on the bike. With more than one LED per pixel, the pixel lights a group of LEDs.

    Marks go into the strip's draft in the segment editor. Tap Apply there, or on the Bike tab, to send them.

    Test flow

    Runs the underglow effect so you can check the mapping by eye. Stop puts the previous underglow settings back.

    Current budget

    Strips now–

    Shared by all four strips; the headlight, pods and DRL take about 15 A when lit, the converter gives 30 A.

    Headlight

    Ticks set which outputs light in each switch position. Two feeds: separate low and high beam wires. Baja LP6 DOT: the high-beam wire lights the whole lamp, so low and high are never on together; pods with high.

    Lamp-out warning

    Switch inputs

    If the Live tab counts input changes while nobody touches the switch, the bike's signal lines are dropping out. A hold keeps every light and signal on through gaps shorter than this; it only delays the switch-off, never the switch-on.

    Handlebar button

    Current readings

    With the load on, measure it with a clamp meter and enter the reading.

    Output test

    Forces one output at a time for bench checks: lamps get 12 V, strips get 12 V and a dim white fill. Only while the bike is parked (lights off, no brake or turn signal). Overrides last 10 minutes; Clear all or key off ends them.
